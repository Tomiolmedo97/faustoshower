# Baby Shower de Fausto

Invitación digital para el baby shower de Fausto.

**Domingo 15 de noviembre de 2026 · 16:00 a 19:00 · Salón Regina**

Sitio: [faustoshower.vercel.app](https://faustoshower.vercel.app)

Los invitados pueden confirmar asistencia y dejar una carta para Fausto. En `/anfitriones`, con la clave, se ven todas las confirmaciones y cada nota con el nombre de quien la escribió.
